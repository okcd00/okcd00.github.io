02

场景与挑战

当业务问题需要被转化为数据库查询时，使用者往往依赖熟悉 SQL 的人员。该项目尝试以自然语言接口降低查询门槛，让询问经过语义处理后转为可执行查询，并将结果反馈给使用者。

CHALLENGE 01

自然语言与查询的映射

不同表达需要对应正确的查询意图和条件，公开介绍将意图检测与槽位填充分开处理。

CHALLENGE 02

问题与数据库的连接

系统需要把问题中的值、列与表联系起来，相关工作包含知识库、实体链接和 Schema 热启动。

CHALLENGE 03

从表达式到可执行查询

公开方案使用中间表示衔接自然语言与 SQL，并包含语法格式修复等后处理。

03

我的职责与边界

  • 作为项目主要负责人，完成系统架构设计与原型实现。
  • 设计知识库，参与自然语言与数据库结构之间的连接。
  • 参与智能语音数据库查询项目的个性化部署及交付。

个人贡献与团队协作

作为项目主要负责人，与开发和前端同事共同完成系统。个人负责整体架构、原型和知识库设计，并参与个性化部署。

04

方案与推进

工作流程概念示意，非系统部署架构。

STEP 01理解问题意图检测与槽位填充
STEP 02连接数据中间表示与知识库
STEP 03返回答案可执行 SQL 与结果呈现
01

自然语言查询的任务拆解

处理意图检测、槽位填充与缺失信息补全，在生成查询后进行语法格式修复等后处理。

02

用中间表示连接语言与 SQL

在自然语言和可执行 SQL 之间加入 IR（Intermediate Representation），结合“值—列—表”反查、数据库 Schema 热启动与实体链接。

03

从查询到业务交付

在连接的数据库执行 SQL，并将结果整理为图表。作为主要负责人对接海通证券，参与中金所智能语音数据检索课题的个性化部署。

05

项目结果

PROJECT OUTCOMES

项目获得 2019 年度研究课题二等奖、第七届证券期货科学技术优秀奖；智能语音数据库查询项目一期已完成验收。以上奖项属于项目成果。

06

研究与资料

Mantra / Aireport / Text2SQL

这是首次作为主要负责人推进的大型完整项目，直接对接海通证券，设计实现数据库自然语言接口的系统框架。

项目于深交所技术大会获 2019 年度研究课题二等奖，并获第七届证券期货科学技术优秀奖。随后课题在中金所中标，参与语音文本转 SQL 的“智能数据检索引擎”研究与个性化部署，一期完成验收。
